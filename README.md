**Word2Vec on Movie Dataset: Exploring CBOW and Skip-Gram Models**
This project demonstrates the application of Word2Vec to learn word embeddings from a movie dataset. Using both the CBOW (Continuous Bag of Words) and Skip-Gram models, it explores how contextual word representations can improve natural language understanding tasks.

Features:
Implementation of CBOW and Skip-Gram models using Gensim.
Dataset preprocessing, tokenization, and embedding generation.
Comparisons between CBOW and Skip-Gram results on the dataset.

Applications:
Analyzing word relationships within the movie dataset.
Demonstrating the strengths of CBOW for frequent words and Skip-Gram for rare words.
